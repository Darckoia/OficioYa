# OficioYa V1 — objetivo de lanzamiento

## Plazo
Objetivo: 8–12 semanas.

## Prioridad P0
1. Cuenta y sesión segura.
2. Acceso de amistades `POCHOKLITO` por 48 horas, vinculado a cuenta y nunca mostrado como código comercial.
3. Negocio persistente por usuario.
4. Productos persistentes con foto, descripción, precio CLP, stock, SKU/EAN.
5. IA rápida para conversación y generación comercial.
6. IA multimodal para análisis de fotos de productos.
7. Confirmación humana de datos generados por IA.
8. Catálogo/vitrina pública permanente.
9. Clientes, presupuestos y pedidos.
10. WhatsApp mediante enlaces preparados para revisión; no se debe afirmar envío automático sin API oficial configurada.
11. Mercado Pago con registro y verificación del estado antes de conceder acceso de pago.
12. Panel administrativo y auditoría básica.

## Reglas de IA
- La IA no inventa precio, stock, horarios, contactos, descuentos ni condiciones.
- Una estimación de precio se etiqueta como estimación y nunca sustituye el precio ingresado/confirmado por el vendedor.
- El router debe usar un modelo rápido para tareas simples y reservar modelos avanzados para tareas complejas.
- Si el proveedor principal falla, usar fallback configurable.
- Las claves de proveedores permanecen exclusivamente en servidor.

## Experiencia
- Chile primero.
- CLP.
- Español chileno como idioma principal.
- Mobile-first, especialmente Android.
- Chat libre como entrada principal; las sugerencias visuales no deben bloquear la conversación.

## Criterio de aceptación
Una amistad puede activar la prueba de 48 horas, crear un negocio, fotografiar un producto, revisar lo que detectó la IA, confirmarlo, guardarlo en inventario, crear una vitrina y generar un mensaje comercial desde el teléfono.
