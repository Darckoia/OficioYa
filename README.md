# OficioYa

Marketplace de servicios para trabajadores independientes y pequeños negocios.

## Objetivo del MVP
Conectar clientes con profesionales por oficio y ubicación, permitiendo descubrir perfiles, solicitar servicios, conversar, recibir cotizaciones y valorar trabajos.

## Módulos
- Autenticación y perfiles
- Profesionales y oficios
- Búsqueda y ubicación
- Solicitudes y cotizaciones
- Chat
- Valoraciones
- Notificaciones
- Panel administrativo

## Arquitectura
Monorepo preparado para frontend web, API y persistencia. El desarrollo se organiza por módulos para llegar rápidamente a un MVP funcional y luego evolucionar a producción.
